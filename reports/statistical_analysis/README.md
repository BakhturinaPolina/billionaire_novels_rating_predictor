# Statistical Analysis Reports

This directory contains detailed draft reports and documentation for the statistical analysis stage of the research project. These reports serve as:

1. **Research article drafts** - Detailed text and findings for the research article
2. **Reproducibility documentation** - Detailed methodology and results for other researchers
3. **Internal reference** - Comprehensive documentation of analysis decisions and outcomes

## Contents

### Data Preparation Reports
- `STRUCTURE.md` - Structure and organization of data preparation outputs

### Model Comparison Reports
- `MODEL_COMPARISON_SUMMARY.md` - Comparison of different topic modeling approaches

### Archived Documentation
Historical reorganization documentation has been moved to `archive/stage10_reorganization_docs/`.

All final datasets for statistical analysis are located in:
