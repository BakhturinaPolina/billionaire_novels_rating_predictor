# Convert Statistical Analysis Notebooks to Python Scripts

## Overview

Convert `01_notebook1_data_validation_extraction_goodreads_id.ipynb` and `02_notebook2_book_aggregation_goodreads_id_excluded5.ipynb` into command-line Python scripts with proper argument parsing, logging, and error handling.

## Structure

### New Directory

- Create `notebooks/07_analysis/statistical_analysis/scripts/` subfolder

### Scripts to Create

#### 1. `01_data_validation_extraction.py`

**Purpose**: Data validation and topic lookup table extraction (equivalent to Notebook 1)

**Key Functions**:

- `load_labels_metadata()` - Load Stage 08 labels JSON
- `load_model()` - Load BERTopic model with fallback to CSV
- `extract_all_fields()` - Extract topic-level table with taxonomy/Radway mappings
- `normalize_id()` - ID normalization helper
- `assert_overlap()` - Overlap diagnostics between datasets
- `main()` - Command-line entry point

**Command-line Arguments**:

- `--model-path` - Path to BERTopic model (with fallback detection)
- `--labels-path` - Path to Stage 08 labels JSON
- `--goodreads-path` - Path to goodreads.csv metadata
- `--output-dir` - Output directory (default: `results/stage10_correlation_analysis/taxonomy_radway_eda`)
- `--excluded-book-ids` - CSV file with excluded book IDs (optional)
- `--project-root` - Project root path (auto-detected if not provided)

**Outputs**:

- `topic_lookup.parquet` - Topic lookup table for merging
- `full_model_data.csv` / `.parquet` - Full topic metadata
- `summary_statistics.json` - QA summary
- `topics_needs_review.csv` - Topics requiring manual review
- `id_alignment_report.csv` - ID overlap diagnostics
- `missing_books_in_outputs.csv` - Missing books report

#### 2. `02_book_aggregation.py`

**Purpose**: Book-level aggregation and derived indices (equivalent to Notebook 2)

**Key Functions**:

- `find_inputs()` - Discover required input files
- `load_table()` - Load CSV/Parquet with auto-detection
- `aggregate_to_book_level()` - Aggregate topic probs to taxonomy proportions
- `compute_indices()` - Compute taxonomy-proxy indices
- `main()` - Command-line entry point

**Command-line Arguments**:

- `--topic-lookup` - Path to topic_lookup.parquet from script 01
- `--book-topic-probs` - Path to book_topic_probs.parquet (auto-discovered if not provided)
- `--chapter-topic-probs` - Path to chapter_topic_probs.parquet (optional)
- `--goodreads-path` - Path to goodreads.csv
- `--output-dir` - Output directory (default: `results/stage10_correlation_analysis/notebook2_book_features`)
- `--excluded-book-ids` - CSV file with excluded book IDs
- `--project-root` - Project root path

**Outputs**:

- `book_taxonomy_main_props_long.parquet` - Long format category proportions
- `book_taxonomy_main_props_wide.parquet` - Wide format for modeling
- `indices_book_taxonomy_proxy.parquet` - Derived indices (love_over_sex, hea_index, etc.)
