# Data Preparation Results

This directory contains outputs from the data preparation pipeline for statistical analysis.

## Directory Structure

- **`topic_probabilities/`** - Topic probability files at book and chapter levels
  - `book_topic_probs.parquet` - Book-level topic probabilities
  - `chapter_topic_probs.parquet` - Chapter-level topic probabilities

- **`book_features/`** - Book-level aggregated features and derived indices
  - `book_taxonomy_main_props_long.parquet` - Long format taxonomy proportions
  - `book_taxonomy_main_props_wide.parquet` - Wide format taxonomy proportions
  - `indices_book_taxonomy_proxy.parquet` - Derived indices aligned to research hypotheses

- **`diagnostics/`** - Data quality and validation reports
  - `id_alignment_report.csv` - ID alignment validation
  - `missing_books_in_outputs.csv` - Missing book tracking

- **`cache/`** - Cached intermediate computations (topic probabilities, transforms)

- **`logs/`** - Execution logs from data preparation scripts

## Source Scripts

Generated by scripts in `src/stage10_correlation_analysis/data_preparation/`. See the source README for detailed documentation on the pipeline.
