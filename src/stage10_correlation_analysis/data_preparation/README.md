# Statistical Analysis Scripts - Data Preparation Guide

This directory (`src/stage10_correlation_analysis/data_preparation/`) contains Python scripts for preparing data for statistical analysis. These scripts convert the Jupyter notebooks (`01_notebook1_*` and `02_notebook2_*`) into command-line tools for reproducible analysis.

**Location**: `src/stage10_correlation_analysis/data_preparation/`
**Outputs**: `results/stage10_correlation_analysis/data_preparation/`

## Overview

The statistical analysis pipeline consists of three main scripts:

1. **`generate_topic_probabilities_final.py`** - Generate topic probabilities at book and chapter levels
2. **`01_data_validation_extraction.py`** - Data validation and topic lookup table extraction
3. **`02_book_aggregation.py`** - Book-level aggregation and derived indices computation

These scripts prepare data for downstream statistical analysis by:
- Generating topic probabilities from sentence-level data
- Validating data quality and ID alignment
- Extracting topic-level metadata (taxonomy, Radway mappings, labels)
- Aggregating topic probabilities to book-level category proportions
- Computing derived indices aligned to research hypotheses

### Required Data Files

Before running these scripts, ensure you have the following data files prepared:

#### 1. Topic Probabilities

**`book_topic_probs.parquet`** (or `.csv`)
- **Source**: Generated by `generate_topic_probabilities_final.py`
- **Location**: `results/stage10_correlation_analysis/data_preparation/topic_probabilities/book_topic_probs.parquet`
- **Required columns**:
  - `book_id` (string or numeric) - Goodreads book ID
  - `topic_id` (integer) - BERTopic topic ID
  - `prob` (float) - Topic probability for this book
- **Format**: One row per (book_id, topic_id) pair
- **Normalization**: Probabilities should sum to 1.0 per book (or close to it)

**`chapter_topic_probs.parquet`** (or `.csv`, optional)
- **Source**: Generated by `generate_topic_probabilities_final.py`
- **Location**: `results/stage10_correlation_analysis/data_preparation/topic_probabilities/chapter_topic_probs.parquet`
- **Required columns**:
  - `book_id` (string or numeric) - Goodreads book ID
  - `chapter_id` (integer, optional) - Chapter identifier
  - `topic_id` (integer) - BERTopic topic ID
  - `prob` (float) - Topic probability for this chapter
- **Format**: One row per (book_id, chapter_id, topic_id) tuple
- **Note**: Used for segment-level analysis if available

#### 2. Topic Labels

**Stage 08 Labels JSON**
- **Source**: Generated during Stage 08 LLM labeling
- **Location**: `results/stage08_llm_labeling/labels_*.json`
- **Format**: JSON dictionary mapping topic_id to metadata:
  ```json
  {
    "0": {
      "label": "Topic Label",
      "scene_summary": "Description of scene type",
      "primary_categories": ["category1", "category2"],
      "secondary_categories": ["setting:location", "activity:action"],
      "is_noise": false,
      "rationale": "Explanation of labeling"
    },
    ...
  }
  ```
- **Alternative**: Simple format `{"0": "Label", "1": "Label", ...}` is also supported

#### 3. Goodreads Metadata

**`goodreads.csv`**
- **Source**: Scraped Goodreads data
- **Location**: `data/processed/goodreads.csv`
- **Required columns**:
  - `ID` (or `goodreads_book_id`, `book_id`) - Goodreads book ID (primary key)
  - `Author` (optional) - Author name
  - `Title` (optional) - Book title
  - `Score` (optional) - Average rating
  - `RatingsCount` (optional) - Number of ratings
- **ID Format**: String or numeric IDs that match `book_id` in topic probability files
- **Note**: IDs will be normalized (stripped, `.0` suffixes removed) for matching

#### 4. BERTopic Model

**Final Model with Taxonomy & Radway Mappings**
- **Source**: Stage 09 category mapping output
- **Location**: `models/retrained/paraphrase-MiniLM-L6-v2/stage09_category_mapping/model_1_with_radway_mappings/`
- **Alternative**: `models/paraphrase-MiniLM-L6-v2/stage09_category_mapping/model_1_with_radway_mappings/`
- **Required attributes**:
  - `topic_representations_` - Topic keywords
  - `topic_taxonomy_` - Taxonomy mappings (Stage 2)
  - `topic_radway_` - Radway function mappings (Stage 3)
- **Note**: If model is not available, script will attempt to load previously exported `full_model_data.csv`

#### 5. Excluded Book IDs (Optional)

**`excluded_book_ids.csv`**
- **Source**: Manual curation or diagnostic output
- **Location**: `notebooks/07_analysis/statistical_analysis/excluded_book_ids.csv`
- **Format**: CSV with `book_id` column listing books to exclude from analysis
- **Default excluded books**: `19561986, 19619918, 25781538, 52061964, 53491034`
  - These books were filtered out before sentence_df creation and have no usable text

## Data Format Specifications

### ID Normalization

All book IDs are normalized to ensure safe joins across datasets:

1. **String conversion**: IDs converted to string type
2. **Whitespace trimming**: Leading/trailing whitespace removed
3. **Float suffix removal**: `.0` suffixes removed (e.g., `"60416566.0"` → `"60416566"`)
4. **Empty value handling**: `""`, `"nan"`, `"none"` converted to `NA`

This normalization is applied automatically by the scripts.

### Expected Column Names

The scripts attempt to auto-detect column names with fallback priorities:

**Book ID columns** (priority order):
1. `book_id`
2. `goodreads_book_id`
3. `ID`
4. `id`

**Topic ID columns**:
1. `topic_id`
2. `topic`

**Probability columns**:
1. `prob`
2. `probability`
3. `topic_prob`
4. `weight`

### Required vs Optional Fields

**Required for script 01**:
- BERTopic model (or exported `full_model_data.csv`)
- Stage 08 labels JSON
- Goodreads metadata (for ID alignment diagnostics)

**Required for script 02**:
- Topic lookup table (from script 01 output)
- Book topic probabilities OR Stage 09 category proportions
- Goodreads metadata

**Optional**:
- Chapter/segment topic probabilities (enables segment-level analysis)
- Excluded book IDs file (uses default if not provided)

## Execution Order

### Step 1: Generate Topic Probabilities

Before running the statistical analysis scripts, generate topic probabilities:

```bash
python src/stage10_correlation_analysis/data_preparation/generate_topic_probabilities_final.py \
    --sentence-df data/processed/sentence_df_with_topics.parquet \
    --model-path models/retrained/paraphrase-MiniLM-L6-v2/stage09_category_mapping/model_1_with_radway_mappings \
    --output-dir results/stage10_correlation_analysis/data_preparation \
    --book-id-source goodreads \
    --goodreads-id-col ID \
    --exclude-book-ids notebooks/07_analysis/statistical_analysis/excluded_book_ids.csv
```

This generates (in `topic_probabilities/` subdirectory):
- `results/stage10_correlation_analysis/data_preparation/topic_probabilities/book_topic_probs.parquet`
- `results/stage10_correlation_analysis/data_preparation/topic_probabilities/chapter_topic_probs.parquet`

### Step 2: Run Script 01 (Validation & Extraction)

```bash
python src/stage10_correlation_analysis/data_preparation/01_data_validation_extraction.py \
    --output-dir results/stage10_correlation_analysis/data_preparation/taxonomy_radway_eda \
    --excluded-book-ids notebooks/07_analysis/statistical_analysis/excluded_book_ids.csv
```

**Outputs** (saved to `data_preparation/taxonomy_radway_eda/`):
- `topic_lookup.parquet` - Topic lookup table for merging
- `full_model_data.csv` / `.parquet` - Full topic metadata
- `summary_statistics.json` - QA summary
- `topics_needs_review.csv` - Topics requiring manual review

**Diagnostics** (saved to `data_preparation/diagnostics/`):
- `id_alignment_report.csv` - ID overlap diagnostics
- `missing_books_in_outputs.csv` - Missing books report

### Step 3: Run Script 02 (Aggregation & Indices)

```bash
python src/stage10_correlation_analysis/data_preparation/02_book_aggregation.py \
    --topic-lookup results/stage10_correlation_analysis/data_preparation/taxonomy_radway_eda/topic_lookup.parquet \
    --output-dir results/stage10_correlation_analysis/data_preparation/book_features \
    --excluded-book-ids notebooks/07_analysis/statistical_analysis/excluded_book_ids.csv
```

**Outputs** (saved to `data_preparation/book_features/`):
- `book_taxonomy_main_props_long.parquet` - Long format category proportions
- `book_taxonomy_main_props_wide.parquet` - Wide format for modeling
- `indices_book_taxonomy_proxy.parquet` - Derived indices

## Derived Indices

Script 02 computes the following taxonomy-proxy indices aligned to research hypotheses:

1. **`love_over_sex`**: `(commitment_hea + bonding_growth + positive_emotions + nonexplicit_affection) - explicit`
   - Measures emphasis on emotional connection vs. explicit sexuality

2. **`hea_index`**: `commitment_hea`
   - Measures "happily ever after" content (reconciliation, commitments)

3. **`explicitness_ratio`**: `explicit / (explicit + commitment_hea + positive_emotions + nonexplicit_affection)`
   - Ratio of explicit sexual content to total romantic content

4. **`dark_vs_tender`**: `(neg_affect + breakup_conflict + violence_threat) - (positive_emotions + nonexplicit_affection)`
   - Measures dark/conflict content vs. tender/positive content

5. **`miscommunication_balance`**: `(commitment_hea + bonding_growth + positive_emotions) - miscommunication`
   - Measures resolution/connection vs. miscommunication/conflict

6. **`luxury_saturation_proxy`**: `elite_work + public_leisure`
   - Measures luxury/business world content

## Troubleshooting

### Common ID Mismatch Issues

**Problem**: Zero overlap between metadata and outputs

**Solutions**:
1. Check that `book_id` in topic probability files matches `ID` column in `goodreads.csv`
2. Verify ID normalization (check for `.0` suffixes, whitespace)
3. Ensure `generate_topic_probabilities_final.py` used `--book-id-source goodreads` and correct `--goodreads-id-col`
4. Review `id_alignment_report.csv` for detailed diagnostics

**Problem**: Low overlap (<95%)

**Solutions**:
1. Check `missing_books_in_outputs.csv` to see which books are missing
2. Verify excluded book IDs are correct
3. Review `missing_books_in_outputs.csv` to trace where books were lost in pipeline

### Missing Data Handling

**Problem**: Model not found

**Solutions**:
1. Check model path in script output
2. Verify model exists at expected location
3. Script will attempt to load exported `full_model_data.csv` as fallback
4. Run script 01 with model available to generate fallback CSV

**Problem**: Labels file not found

**Solutions**:
1. Check `results/stage08_llm_labeling/` for available label files
2. Script will attempt to find newest `labels_*.json` file in directory
3. Provide explicit path with `--labels-path` if needed

### Cohort Exclusion Logic

The scripts exclude books that never produced any sentence rows. Default excluded books:
- `19561986` - The Tycoon's Vacation
- `19619918` - The Tycoon's Proposal
- `25781538` - The Tycoon's Revenge
- `52061964` - Reverie
- `53491034` - The Billionaire's Salvation: Max

These books are excluded because they were filtered out before `sentence_df` creation, meaning they have no usable text for analysis.

To customize excluded books:
1. Create/edit `excluded_book_ids.csv` with `book_id` column
2. Provide path with `--excluded-book-ids` argument
